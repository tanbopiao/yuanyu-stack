# yuanyu-stack 元御 · 智能体安全治理架构

六层 + 一横切的治理闭环白皮书与自检清单。命名取「元」为本源、「御」为驾驭——治理不是把智能体关死，是让它可被信任地跑起来。

详见 [ARCHITECTURE.md](ARCHITECTURE.md) 与 [checklist.md](checklist.md)。
